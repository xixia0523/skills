# GitHub 安装与手动重装

使用 Codex 内置 `skill-installer` 及其 GitHub helper。本项目没有自定义安装器或安装钩子。标准安装消息为：

```text
$skill-installer install https://github.com/xixia0523/skills/tree/main/android-call-chain
```

## 下载前检查

1. 确定内置安装器的实际目标：优先使用显式 `--dest` 指定的 skills 根目录，否则使用 `$CODEX_HOME/skills`，默认是 `~/.codex/skills`。最终目标为该根目录下的 `android-call-chain`。同时检查当前会话报告的同名本地安装；不要把仓库源码或下载的 checkout 当成已安装 Skill。
2. 在下载或申请安装写入权限前检查这些路径。已有目录、文件或符号链接均视为冲突，包括不完整安装及悬空链接；使用 `lstat` 或 `lexists` 等能识别悬空链接的检查方式。若读取受限，按当前宿主支持的机制申请必要的读取权限；无法获得读取权限时，说明无法确认旧安装状态并停止，不要把不可读取视为不存在。
3. 发现任一已有安装时停止。给出经核实的绝对路径、经过 shell 安全引用的手动删除命令，以及上面的标准安装消息。由用户在自己的终端删除旧安装，再重新发送安装请求。Agent 不执行删除，不申请删除或替换权限，不改名、不覆盖、不换安装名，也不下载到临时目标绕过冲突。
4. 确认不存在旧安装后，按内置安装器的说明，直接使用其 GitHub helper 安装到实际目标。需要网络或目标写入权限时，复用已有授权；若当前宿主允许且提供原生审批机制，通过该机制申请必要权限，获准后继续。真实拒绝、明确禁止或审批机制不可用时，说明具体原因和来源，并给出使用当前 helper 与实际目标的手动安装命令。不要另写安装脚本或绕过宿主限制。
5. 若安装器随后报告目标冲突，返回第 3 步，不能改用覆盖逻辑。成功后报告实际安装路径，并说明下一轮消息即可使用；若仍未出现，可重启 Codex。安装不会授予后续源码联网访问或报告写入权限。

## 已有安装时的回复

说明已检测到 `android-call-chain`，本次安装已停止。给出实际安装路径，以及供用户在本机终端运行的删除命令。下面仅为默认路径示例；实际回复必须替换为经核实的绝对路径，兼顾 `CODEX_HOME` 或显式目标：

```bash
rm -rf -- "$HOME/.codex/skills/android-call-chain"
```

如果最后一级是符号链接，删除命令应指向链接本身，不解析为链接目标，也不添加结尾斜杠。只删除该 Skill 安装项，不删除整个 `skills` 目录、仓库源码或工作区报告。

用户手动删除后，在 Codex 中重新发送：

```text
$skill-installer install https://github.com/xixia0523/skills/tree/main/android-call-chain
```

## 内置安装器的执行边界

内置安装器拒绝已存在的目标，但可能先下载仓库再检查目标，也不会在安装前自动执行本仓库的 `SKILL.md` 或本文件。因此，仓库内的规则不能改变内置脚本的检查顺序，也不能保证单独发送标准安装消息时必然在下载前停止。

要明确要求下载前检查，在同一条安装消息中补充：

```text
安装前先检查本地是否已有 android-call-chain；若有则停止，给出实际路径、手动删除命令和标准安装指令，不要自行删除、覆盖、改名或临时安装。
```

GitHub URL 指向远端 `main` 分支下包含 `SKILL.md` 的 `android-call-chain` 目录。安装获取远端内容；本地修改需要提交并推送后才会影响 GitHub 安装。
